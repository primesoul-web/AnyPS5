# libSceNpTrophy2 technical debt

### Silent stubs

- [libSceNpTrophy2](../../../core/libs/prx/libSceNpTrophy2/src/GameInfo.cpp): `sceNpTrophy2RegisterUnlockCallback` accepts a callback that is never called, as no trophy is ever unlocked, `sceNpTrophy2UnregisterUnlockCallback` only returns success, and `sceNpTrophy2ShowTrophyList` returns success without showing a list (there is no system trophy UI; seen on PPSA15552).
- the four icon getters ([GameIcon](../../../core/libs/prx/libSceNpTrophy2/src/GameInfo.cpp), [GroupIcon](../../../core/libs/prx/libSceNpTrophy2/src/GroupInfo.cpp), [TrophyIcon](../../../core/libs/prx/libSceNpTrophy2/src/TrophyInfo.cpp), [RewardIcon](../../../core/libs/prx/libSceNpTrophy2/src/Context.cpp)) write the icon size 0 when the caller asks for it and then throw: there is no trophy-set file on the host to read an icon from. The signatures follow [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/5dfdb4b0b166e83dc9ae275001afb695f12c7174/src/SharpProspero/Interop/Np/NpTrophy2.cs), which recovered `(context, handle[, trophy id], buffer, size)` from the module binary; the buffer's use and the size the console reports for a missing icon are unknown, so a null buffer only skips the size write and the throw is unchanged
